# Artwork and calendar

- Unused portrait asset, Gandalf: **wezlo**, distributed by [ClipSafari](https://www.clipsafari.com/clips/o203289-gandalf) under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The SVG is stored locally as gandalf.svg, recolored in warm gold for dark backgrounds; path geometry is unchanged. Fan artwork; not official artwork.
- Banner, the nine colored walking Fellowship characters, and the animated Smaug guardian: original SVG illustrations created for this profile, inspired by Tolkien's characters; not official artwork. Characters use stylized costumes and color palettes inspired by the film adaptations, without claiming photorealism. Gandalf has a pointed hat and staff; Aragorn a cloak and sword; Legolas a bow; Gimli a helmet, beard and axe; Boromir a shield; the four hobbits have short figures and travel gear. The sourced portrait is retained as an unused asset, not displayed in the README.
- Calendar: fetched from https://github.com/users/antoniomarcoos/contributions. Dates and activity levels match the public calendar at generation time; colors are adapted to the profile theme. It displays contribution levels, not a count of commits.
- Update: GitHub Actions runs daily at 06:23 UTC and can be started manually from Actions. No personal access token is required. Only publicly visible calendar information is fetched.
- If GitHub changes its calendar HTML or a fetch fails, generation fails and the previous SVG remains available.

- Current Smaug banner: `smaug-guardian.svg`, the original animated vector illustration, matching the walking characters. The realistic raster variation is retained as an unused asset and is not shown in the README.

- Technology icons: [Devicon](https://github.com/devicons/devicon), MIT license; [Ruff icon from Simple Icons](https://github.com/simple-icons/simple-icons), CC0. Recoloured to match the profile. Brand marks remain the property of their respective owners.
